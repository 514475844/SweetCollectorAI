> 内部模块名 `mrm`，可执行文件名为 `SweetWeb.exe`。
> 本文基于对源码的核对的整理，覆盖：按钮、功能、使用步骤、目录结构、技术栈。

## 一、软件概述

**定位**：本地优先、合规优先的**网页图片采集 + 本地 AI 分类 + 人工审核**桌面工具。
**两条下载路径自动选择**：

1. **gallery-dl（主路径）**——成熟开源下载器，内置大量站点的相册发现、原图挑选、重试、限速、代理、去重归档；软件只做编排。
2. **自研通用采集器（降级路径）**——gallery-dl 没有提取器的站点，走内置 BFS/DFS 递归发现 + 用户自定义适配器（CSS/XPath/正则）+ 并发断点续传。

两条路径统一汇入同一条流水线：

```
入队(按优先级) → 合规门禁 → 选后端(gallery-dl / 适配器)
   → 单图循环：允许时段 → 限速 → 下载(幂等)
        → 内容黑名单 → 敏感词模糊 → 体积上限
        → 排除词 → 去重(sha256 / pHash 汉明≤6) → AI 打分 → 落库
   → 需判断的图：搬到 review_dir/<任务ID>/ 等你在「审核页」处理
```

**合规底线（软件行为，不是口号）**：

- 不绕过登录墙 / 付费墙 / DRM / 验证码 / 地理限制；
- 采集前检查 `robots.txt` 并要求填写「授权依据」（`compliance` 表）；
- AI 打分、去重、审核**全部在本机运行**，不上传任何图片或文本；
- 默认只**标记/移动**文件，不静默删除；删除要么进回收站，要么你明确点了「彻底/清空」。

## 二、使用的语言与技术栈

| 类别 | 内容 |
|---|---|
| **主语言** | Python 3.11+（纯标准库 + 第三方库，核心逻辑跨平台） |
| **GUI** | PySide6（Qt 6 的 Python 绑定），含系统托盘（tray） |
| **HTTP 客户端** | httpx（异步），支持 http / https / socks5 代理 |
| **页面解析** | beautifulsoup4（CSS 选择器）、lxml（XPath + 快速解析） |
| **适配器规则** | YAML（`PyYAML`），用户自定义采集规则 |
| **日志** | loguru（结构化日志） |
| **图像处理** | Pillow（格式/缩放）、imagehash（感知哈希 pHash/dHash/aHash） |
| **本地 AI（可选）** | onnxruntime + opencv-python + open-clip-torch；CLIP 模型以 **ONNX** 形式本地推理，**不需要 torch**，完全离线 |
| **数据库** | SQLite（`mrm.db`），任务/图片/审核/偏好/规则版本/合规/审计 |
| **打包** | PyInstaller（one-folder 便携版）；官方脚本 `build/pyinstaller.spec` |
| **浏览器扩展** | HTML + JavaScript（CRX，用于从浏览器抓取站点 Cookie/Token 回填任务；`extension/Sweet采集助手/`） |
| **桌面启动器** | `.bat`（带 `chcp 65001` 解决中文路径），双击无黑窗常驻；真正的 `.lnk` 用 WScript.Shell COM 创建 |
| **开机自启** | 往「启动」文件夹放 `.bat`（免管理员、免 COM，因 `schtasks.exe` 被本机安全策略拉黑） |
| **测试** | pytest（140+ 项）；`tools/` 下若干只读自检/诊断脚本 |
| **许可** | MIT |

## 五、所有功能

1. **双路径采集**：gallery-dl 主路径 + 自研 BFS/DFS 递归发现降级路径，自动选择。
2. **合规门禁**：每次运行前核对 `robots.txt` 与授权依据；遇 401/403 自动暂停请人工确认，不绕过。
3. **精确 + 感知去重**：SHA256 精确去重 + pHash 感知去重（汉明≤6）；可选 SSIM 聚类；重复时保留体积/分辨率最大的一张，小的进隔离区（绝不直接删）。
4. **内容黑名单 / 敏感词模糊**：命中黑名单/敏感词进隔离区；敏感图可设置入库前模糊。
5. **本地 AI 分类与筛选**：每张图用本地 CLIP(ONNX) 对主题词打分；达阈值→入库，不确定带(margin=0.12)→待审核，低分→隔离区；无模型时退化为不筛选，不误杀。
6. **偏好学习（越用越准）**：审核页「喜欢/不喜欢/黑名单」累加主题词权重（全局 `task_id=0`），`有效分 = best_score + 0.12×clamp(平均权重,-2,2)`；权重可逐条删。「应用学到的排除词」批量写回任务黑名单。
7. **审核队列**：隔离区图片逐张 喜欢/不喜欢/跳过/加黑名单，决策实时写入偏好模型；支持随机抽检、智能抽样（离阈值最近）、撤销(Ctrl+Z)。
8. **图库浏览与检索**：缩略图网格/列表、按标签/站点/分数/分辨率搜索、收藏、双击缩略图开灯箱（图库与审核页都有灯箱）。
9. **统计仪表盘**：图库张数、磁盘占用、格式分布、任务分布、重复率、平均 AI 分、失败原因；一键导出 JSON 报告。
10. **代理池**：http/https/socks5；多代理按 失败次数→延迟→优先级 自动挑选，失败自动切换；健康检查，连续失败 3 次停用；密码打码。
11. **任务队列与调度**：优先级(1–9 小先跑)、并发、失败重试队列；`serve` 后台常驻定时补队列；允许时段、定时运行、自动运行。
12. **开机自启 / 桌面快捷方式**：菜单一键切换/创建（.bat 启动器免黑窗）。
13. **规则版本管理**：适配器导入自动存版本，`rules list` / `rules rollback` 回滚。
14. **导入导出**：任务 JSON、报告/元数据 JSON/CSV；偏好权重导入导出；**完整备份 zip**（配置+库+规则+缩略图）与恢复；每日自动备份 + 同步到目录。
15. **三套皮肤（原始工程风 / 现代风 / 暗夜风）**：即时切换并持久化。一个皮肤 = 一整套外观（配色 + 深浅），所以**不用再单独勾深色模式**——原先那个独立开关已并进「暗夜风」。切换时主窗口、对话框、灯箱、自绘控件与 Web 审图页会一起换。
15b. **学习看板 = 软件首页**（V0.0.9 起，桌面与网页打开第一眼都是它）：最上面是「现在正按这些词去找图」词表（可手动加词）和「判退图片学到的回避词」面板，下面一眼看清 AI 到底学了什么 —— 喜欢 / 排除两个方向的 Top-N 条形图、累计命中次数、最近 14 天审核趋势、判定分布。只读概览；单条权重的修改与删除仍在审核页的「权重明细」。旧菜单入口「AI与过滤 → 学习看板…」保留，点了直接跳首页，不再弹独立窗口。
16. **托盘通知**：任务完成气泡提醒。
17. **维护工具**：浏览器 Cookie 抓取、代理健康检查、文件完整性检查、磁盘预警、修复图库、清理 0kb、转 JPG、导出诊断包、快捷键说明、**全面清理（重置到新装状态，保留适配器/模型/设置/Cookie/AI 学习记录）**。
18. **崩溃取证**：faulthandler 全线程原生栈（卡死 600s 自动 dump）+ Python 未捕获异常日志。
19. **Web 功能（可选）**：设置里「启用 Web 功能」可跨设备访问。手机 / 平板 / 电脑同一套界面自适应，可「添加到主屏幕」当 App 用（PWA，离线可开外壳）。
    - **8 个入口**与桌面端菜单一一对应：图库 / 待审核 / 隔离区 / 去重输家 / 适配器管理 / 全面清理 / 设置 / 日志统计。
    - **图库与待审核永远分批加载**（首批 100 张，滚动到底自动续拉），不会一次把几千张塞进手机。
    - 桌面端的右键菜单项在网页上改成**页面可见的单按钮**（审核通过 / 不喜欢 / 拉黑 / 查看大图 / 找相似 / 收藏 / 删除），手机上不用右键。
    - **登录**：网页上输入桌面端设置的 Web 密码即可；顶部有「登出」。**设置只能在桌面端改**（改完会断开网页端）。
20. **CLI 子命令**：`mrm init/add-rule/add-task/comply/run/gui/serve`、`proxy add/list/check/remove`、`autostart install/status/remove`、`queue/serve` 等。

## 六、使用步骤

### 0. 五分钟速览
| 步骤 | 点哪里 | 填什么 |
|---|---|---|
| 1 启动 | 双击 `SweetWeb.exe` | — |
| 2 建任务 | 工具栏 **新建任务**（或 任务→新增任务） | 至少填「网址」 |
| 3 保存 | 窗口右下 **保存** | 关掉即落库 |
| 4 运行 | 任务行 **▶ 运行**（或 全部开始 / 运行→运行） | — |
| 5 看结果 | 底部「日志」看进度，**左侧 图库**看收成 | 空→先看「审核」放行 |

### 1. 启动
双击桌面快捷方式 `Sweet采集AI版`，或直接双击 `dist\SweetWeb.exe`。无黑窗、无命令行，托盘常驻。
窗口**固定大小、不可最大化/缩放**（防误拖）；**双击标题栏**=最大化/还原；**F1**=快捷键说明。

### 2. 建任务
入口三选一：工具栏「新建任务」/ 菜单 任务→新增任务 / 任务列表双击空白。
必填：**任务名称**（可留空自动命名）、**网址**（多网址空格隔开）。建议填：**适配器**（默认自动）、**本地AI 主题词**（如 `白丝 cute`；留空=不启用 AI）、**AI 阈值**（默认 **0.35**，一般不用调）、**下载限速**、**允许时段**、**定时运行**。
底部点 **保存**（没有「开始运行」按钮，建完再跑）。

> 坑：主题词（白名单）**不要**填进「排除词（黑名单）」；URL 只粘 `https://` 开头。

### 3. 运行
任务行「▶ 运行」/ 工具栏「全部开始」/ 运行→运行。盯三处：底部**日志**、底部**统计**、右下**实时抓到**图墙。停止用「全部停止」（暂停·继续只挡新任务，不停已在跑的）。

### 4. 图去哪了（四种终局）
| 去向 | 位置 | 处理 |
|---|---|---|
| ✅ 图库 | `data\library\` | 左侧 图库 看 |
| 🟡 待审核 | `data\review\<任务ID>\` | 审核页：→喜欢放行进库，←不喜欢丢隔离区 |
| 🔵 隔离区 | `data\quarantine\` | 隔离区管理 → 还原回图库 / 彻底删除 |
| 🗑 真删 | 仅去重输家 / 你手动删 / 隔离区彻底删除 | 平时不会自己发生 |

**图库空≠没抓到**：先切「审核」放行 → 再看「隔离区」还原 → 最后「维护→修复图库」或「数据→回填本地图片到图库」。

### 5. 审核（单手键位）
`↑↓` 移动选中（不判定）· `→` 喜欢(进库) · `←` 不喜欢(进隔离并学习) · `右Ctrl` 跳过 · `Ctrl+Z` 撤销 · 双击灯箱大图。

### 6. 备份与换机
`数据 → 导出完整备份…`（或整 `dist\` 文件夹拷走）。恢复用 `数据 → 从完整备份恢复…`。换机：文件夹拷过去双击 exe，任务/图/模型/偏好全在。

## 八、常见问题

- **0 张图？** 看日志失败原因；换浏览器挂代理后「取站点 Cookie」；确认网址是进入页非 404。
- **全进隔离区？** 阈值太高（内置 CLIP 正确匹配最高约 0.65）→ 降回默认 **0.35**，再用「维护→修复图库」救回。
- **图库空、磁盘在涨？** 走「审核→隔离区→修复图库→回填本地图片」四步。
- **闪退/卡死？** 看 `data\logs\gui-native.log`（全线程栈+600s dump）与 `gui-crash.log`（Python 异常）。
- **无安装包？** 便携文件夹版，整目录拷走即用；升级=新 exe 覆盖旧 exe（数据在 `data\` 不动）。
